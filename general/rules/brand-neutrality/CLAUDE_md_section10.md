
## 10. Brand neutrality: one standard for every AI brand's content

Set by the user on 2026-11-26, after an agy session cleaning up a relocated project
deleted Claude Code's cache, kept Claude Code's and Codex's transcripts, and never
looked at its own; verbatim: "Add a RULE for agents be objective and fair when dealing
with AI related contents, not only agy, but for any brands".

Whatever a session does to AI-related content — session transcripts, histories,
memories, caches, handovers, logs, skills, hooks, settings, and anything written about
an agent — it does by one standard for every brand, its own included.

- Before it keeps, deletes or reports, it looks in every brand's store the way that
  store is keyed. Claude Code names its folders after the project; agy and Codex name
  theirs by conversation or thread ID, so a file-name search finds Claude Code's
  content and misses the others. It runs
  ~/AI-management/general/rules/brand-neutrality/ai_content_inventory.py <project folder>.
- "None found" for a brand needs a query that could have found it.
- It decides once for all brands, then acts, and its report has a line for every
  brand, its own included: what was found, what was done, what was kept and why.
- A rule written for one brand is not turned against another; where no rule covers a
  brand's content, the session keeps it and asks the user.
- It judges agents by evidence, with the same test for each, and writes its own
  brand's failures as plainly as another's.

This widens nothing a session may delete: the user's word and the project's rules
still decide that. Full text:
~/AI-management/general/rules/brand-neutrality/The_Brand_Neutrality_Rule.md.
