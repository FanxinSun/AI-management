## Exit gate

`tests/test_vault.py` is written first and its failing run is saved; after the implementation it passes (exit 0), and
that run is saved too. The tests show: directory mode `0700` and file mode `0600`; an atomic write that leaves no
`.partial` behind; `remove` of any `@*:default` handle refuses with exit 2; the sha256 of
`$HOME/.claude/settings.json`, `$HOME/.codex/config.toml` and `$HOME/.gemini/antigravity-cli/settings.json` is the same
before and after the whole run. The test home is a temporary directory (`OMNI_HOME` and `HOME` both point into it), so
no test touches the real accounts.
