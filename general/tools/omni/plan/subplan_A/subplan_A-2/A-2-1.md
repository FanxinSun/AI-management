# A-2-1 — agy and codex adapters

Step 1 of A-2 ([`../A-2.md`](../A-2.md)). Status: **pending**. Files: `omni/adapters/agy_cli.py`,
`omni/adapters/codex_cli.py`. Both parse the fixtures that A-0 saved, not guesses.

## agy

- Command: `agy -p --output-format stream-json [--model <slug>] [--effort <lvl>] [--mode plan] [--conversation <id>]`,
  prompt on stdin. `--mode plan` is added when `RunOptions.mode` is `read-only`; `--conversation <id>` when a native
  session id is given. Model and effort are flags of the one call, so no settings file of agy is written.
- `list_models()`: runs `agy models`, cuts lines at `\n`, skips the first line (`Fetching available models...`) and
  any line without a tab, and takes the text before the tab as the slug.
- Environment: `child_env(profile, ...)`.

## codex

- Command: `codex exec --json --skip-git-repo-check [-m <slug>] [-c model_reasoning_effort="<lvl>"] -s <read-only|workspace-write> -`,
  prompt on stdin (the final `-`); with a native session id: `codex exec resume <id> --json -`.
  `read-only` maps to `-s read-only`, `workspace` to `-s workspace-write`.
- `list_models()`: the `slug` values in `<CODEX_HOME>/models_cache.json` (default `$HOME/.codex`), read with `json`.
- Environment: `CODEX_HOME` from `child_env`. No `codex app-server` is started by omni; if the default profile's
  socket contention shows up in the probe, the executor reports it and the planner decides.

## Both

Map the CLI's event types to `StreamEvent` kinds as the fixture shows them: reasoning to `thinking`, tool use to
`tool_start` and `tool_end`, answer text to `text`, usage and session ids to `meta`, a failure to `error`. A line that
does not parse, or an event type not in the fixture, becomes a `meta` event holding the raw line and does not raise. A
429 or `try again at HH:MM` text becomes an `error` event whose `meta` has `rate_limited: true`.
