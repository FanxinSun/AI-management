## Types

- `StreamEvent(kind, content, meta)`: `kind` is one of `thinking`, `tool_start`, `tool_end`, `text`, `meta`, `error`;
  `content` is a string; `meta` is a dict (token counts, tool name, native session id and similar).
- `RunOptions(model=None, effort=None, mode="read-only", native_session_id=None, timeout_sec=300.0)`; `mode` is
  `read-only` or `workspace`.
- `AgentAdapter`, abstract: `provider` (string), `list_models() -> list[str]`, `auth_state() -> str`
  (`ok`, `missing`, `unknown`), `run(prompt, opts) -> AsyncIterator[StreamEvent]`.
- `get_adapter(profile: ProfileSpec) -> AgentAdapter` in `omni/adapters/__init__.py`, choosing the class by
  `profile.provider` and giving it `child_env(profile, os.environ)` from A-1-1.

## `stream_subprocess_jsonl(cmd, env, stdin_text, timeout_sec)`

An async generator over `asyncio.create_subprocess_exec` with `stdin`, `stdout` and `stderr` piped. It writes the
prompt as UTF-8 to stdin and closes stdin at once, reads stdout in chunks and cuts lines at `\n` only (never
`splitlines()`), yields each non-empty line as text, and at the end yields a final marker with the exit status and the
last 2000 characters of stderr. On timeout it terminates the child, waits for it, and ends with an `error` marker. No
argument of `cmd` ever contains the prompt.
