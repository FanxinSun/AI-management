## claude

- Command: `claude -p --output-format stream-json --verbose [--model <slug>] [--effort <lvl>] [--permission-mode <plan|acceptEdits>] [--resume <id>]`,
  prompt on stdin. `read-only` maps to `--permission-mode plan`, `workspace` to `--permission-mode acceptEdits`. Every
  flag is checked against `claude --help` and the A-0 fixture; a flag the binary does not know is dropped and the
  difference is reported, not guessed around.
- Environment: `CLAUDE_CONFIG_DIR` from `child_env` for a non-default profile.
- `list_models()`: the aliases `fable`, `opus`, `sonnet`, `haiku`, plus any model name found in the profile's
  `settings.json` key `model`, read with `json`.
- The `claude` binary has crashed with a Bun panic when started inside the planner's sandbox. The adapter runs on the
  host; a crash is an `error` event with the last stderr text, never a retry loop.

## http_sse

- `urllib.request` with `ssl.create_default_context()`. Never `CERT_NONE`, never `check_hostname = False`.
- OpenAI-compatible: `POST {api_base}/v1/chat/completions` with `"stream": true`. Anthropic: `POST {api_base}/v1/messages`
  with `"stream": true`. The key is read from the environment variable named in `ProfileSpec.env_key_var` at call time
  and goes only into the request header; it is never logged, stored or printed.
- Server-sent events are cut at `\n`; only `data:` lines are used; `[DONE]` ends the stream. Delta text becomes `text`
  events. An HTTP error becomes an `error` event with `rate_limited: true` for status 429.
- Tests use a local `http.server` on `127.0.0.1` that sends a canned SSE body; no real endpoint is called.
