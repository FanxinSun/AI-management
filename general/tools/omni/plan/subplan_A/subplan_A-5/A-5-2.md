## Commands (`argparse`; exit codes `0`, `1`, `2`, `130`)

- `omni [--thread <id|title>] [--new <title>] [-a <@handle>] [--model <slug>] [--effort <lvl>] [--mode <read-only|workspace>]` starts the REPL.
- `omni ask -a <@handle> [--model <slug>] [--effort <lvl>] [--mode <read-only|workspace>] [--thread <id>] [--json] [PROMPT|-]`
- `omni compare -a <@h1,@h2,...> [--with-prev] [--summarize] [--judge <@handle>] [--mode <read-only|workspace>] [--json] [PROMPT|-]`
- `omni summarize [--thread <id>] [--turn <seq>] [--judge <@handle>] [--json]`
- `omni accounts <list|status|import-default|login|remove> ...` as in A-1-1
- `omni models [--provider <claude|agy|codex>] [--json]`
- `omni threads <list|show|export> [--thread <id>] [--format <md|json>] [--out <path>]`

`PROMPT` is the last argument, or `-` to read it from stdin. `--json` prints one JSON object per turn, one per line.

## Launcher

`bin/omni` starts with `#!/usr/bin/env python3`, resolves its own location with `os.path.realpath(__file__)`, puts the
tool directory first on `sys.path`, and calls `omni.cli.main()`. No path in it is machine-specific, so a symlink in
`~/.local/bin` works.

## Installer

`install-omni.sh` (`set -euo pipefail`): links `${LOCAL_BIN:-$HOME/.local/bin}/omni` to `bin/omni`, runs
`python3 -m py_compile` over every `.py` file, and runs `python3 -m unittest discover` from the tool directory. It
changes no agent configuration and creates no `omni` data until the first run.
