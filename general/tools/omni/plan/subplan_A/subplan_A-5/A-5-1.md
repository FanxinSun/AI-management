# A-5-1 — Scrollback REPL

Step 1 of A-5 ([`../A-5.md`](../A-5.md)). Status: **pending**. File: `omni/repl.py`.

The REPL never enters the alternate screen, so history stays in the terminal's scrollback. `readline` gives line
editing and history (history file under `${OMNI_HOME}`, mode `0600`); `rich` is used when importable, with a plain ANSI
fallback.

## What is drawn

- Header: `[<N>] <Title> · Active: <@handle> (<model> · <effort>) · Mode: <mode>`, then a line with the participants.
- Above each answer, folded: `[Thinking <sec>s · <N> lines — /thinking to expand]` and `[Tools (<K>) — /thinking to expand]`
  (`<N>` is the count from `thinking.split('\n')`).
- A compare turn shows the quoted prompt first, then the new agent's name and answer.
- After every reply: `Compare: [c1] <@a>  [c2] <@b>  [c3] <@c>  |  [s] /summarize`, listing up to three handles that
  have not yet answered that prompt.

## Input

- `@h1 [@h2 ...] <prompt>`: one or more handles; several run in parallel through `run_compare`.
- `/switch <@handle>` (alias `/use`), `/compare [@h1 ... | all] [--turn <N>] [--with-prev]`, `/c1` `/c2` `/c3`,
  `/summarize [@judge]` (aliases `/s`, `/synth`, `/diff`, `/consensus`), `/thinking [last|<seq>]`, `/accounts`,
  `/models`, `/model <slug>`, `/effort <lvl>`, `/mode <read-only|workspace>`, `/threads`, `/new [title]`,
  `/resume <id|title>`, `/export [md|json] [path]`, `/help`, `/quit`.
- `/model` and `/effort` change only the next calls of the REPL's own state; they never write an agent's settings file.
- Ctrl-C during a call cancels that call and returns to the prompt; Ctrl-D or `/quit` leaves with exit 0.

## Tests

A pure function `parse_input(line) -> Command` carries all parsing, so the tests need no terminal: they cover each
command above, an unknown `/command`, an empty line, and a handle that is not registered (a usage error shown in the
REPL, never an exception).
