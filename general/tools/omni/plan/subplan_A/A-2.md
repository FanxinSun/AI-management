## Exit gate

- `tests/test_adapters.py` fails first (saved), then passes (exit 0, saved). It replays the three fixture files of A-0
  through the three parsers and checks the produced `StreamEvent` sequence, and it feeds each parser a truncated line,
  an unknown event type and a 429 error line to check that none of them raises.
- A live read-only probe, `python3 tests/live_probe.py --handle <@handle> --prompt 'Reply with the single word PONG.'`,
  for `@claude:default`, `@agy:default` and `@codex:default`, run with `OMNI_HOME` set to a temporary directory. Each run
  prints the events it received and exits 0 when a `text` event arrived and 1 otherwise. All three outputs are saved.
- Any flag in the step files that the probe of A-0 shows to be wrong is corrected from the saved output, and the
  difference is written in the report.
