# A-0 — Host stream-schema probe

Step 0 of sub-plan A in [`../PLAN.md`](../PLAN.md) section 2. Status: **pending**. Executor: `omni-tree` (order TREE-01).
Was O-0 in the first draft.

## What to do

Run, on the host and outside any sandbox, one tiny prompt through each CLI, with the prompt on stdin, and save the raw
output of each run in a scratch directory outside the repository:

```bash
printf 'Reply with the single word PONG.\n' | claude -p --output-format stream-json --verbose
printf 'Reply with the single word PONG.\n' | agy -p --output-format stream-json
printf 'Reply with the single word PONG.\n' | codex exec --json --skip-git-repo-check -s read-only -
```

Every run goes through the job logger (start, end, exit status, command).

## Output

- `tests/fixtures/claude_stream.jsonl`, `tests/fixtures/agy_stream.jsonl`, `tests/fixtures/codex_stream.jsonl`: the
  sanitized copies, one JSON object per line, written as `<name>.partial` and then `os.replace`d.
- Sanitizing removes session ids and UUIDs, absolute paths, e-mail addresses, tokens and account names, and nothing
  else: event types, field names and the nesting stay as the CLI printed them.
- A short note in the executor's report that lists, for each CLI, the event types seen and the field that carries the
  answer text and the field that carries reasoning, each copied from the saved output.

## Stop and report

If a CLI exits non-zero, crashes, or does not read its prompt from stdin, stop and report with the exact output. The
planner decides the replacement; the executor does not choose another invocation.

## Exit gate

The three fixture files exist, each parses line by line as JSON, and `grep -rnE '(/home/|@[A-Za-z0-9.-]+\.[a-z]{2,}|[0-9a-f]{8}-[0-9a-f]{4}-)' tests/fixtures`
matches nothing.
