# A-1-0 — Vault layout, permissions, atomic store

Step 0 of A-1 ([`../A-1.md`](../A-1.md)). Status: **pending**.

## Root and permissions

- Root: `${OMNI_HOME:-$HOME/.local/share/omni}`. Every directory omni creates there is `os.chmod`ed to `0o700`, every
  file to `0o600`.
- Every write of a file that another step reads goes to `<name>.partial` first, is flushed and `os.fsync`ed, then
  `os.replace`d onto `<name>`.

## `ProfileSpec`

A dataclass with these fields: `handle` (for example `@claude:default`), `provider` (`claude`, `agy`, `codex`, `http`),
`profile` (the part after the colon), `is_default` (bool), `config_dir` (string path, empty for `http`),
`default_model`, `default_effort`, `cooldown_until` (ISO 8601 string or empty), `api_base` (HTTP only),
`env_key_var` (HTTP only: the name of the environment variable that holds the key, never the key itself).

## `accounts.json`

`${OMNI_HOME}/accounts.json`, `{"version": 1, "active_handle": "...", "judge_handle": "...", "profiles": {"<handle>": {<ProfileSpec fields>}}}`.
Handle syntax: `@<provider>:<profile>` with `<profile>` matching `[A-Za-z0-9._-]{1,32}`; anything else raises
`VaultUsageError`, which the CLI turns into exit code 2.

## Interface

`Vault(home: Path)` with `load()`, `save()`, `get(handle)`, `put(spec)`, `delete(handle)`, `all()`. No method reads or
prints a credential.
