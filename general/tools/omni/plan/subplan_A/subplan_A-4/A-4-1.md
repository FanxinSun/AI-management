# A-4-1 — History chain, blind versus peer-aware compare, delta sync

Step 1 of A-4 ([`../A-4.md`](../A-4.md)). Status: **pending**. File: `omni/context.py`.

## `build_prompt_packet(store, thread_id, parent_turn_id, user_prompt, with_prev=False, target_handle=None, mode="read-only") -> str`

- **History.** Walks `chain_to_root(parent_turn_id)` and writes the turns, oldest first, inside `<thread_history>`, each
  as `<turn role=".." handle="..">text</turn>`. So a thread that went `@claude`, then `@codex`, then `@claude` again
  gives every agent the whole conversation.
- **Blind compare (default).** A compare request is built from the parent of the user prompt it repeats. The packet holds
  the prompt and the history before it, and no sibling answer to that prompt.
- **Peer-aware compare (`--with-prev`).** The packet also holds `<peer_responses>` with the sibling assistant answers to
  that prompt, each tagged with its handle.
- **Workspace mode delta.** When `mode` is `workspace` and `(thread_id, target_handle)` has a `native_session_id`, the
  agent resumes its own session, and the packet holds only the turns after `last_synced_turn_id`. After a successful
  call the caller moves `last_synced_turn_id` to the newest turn.
- The user prompt is last, inside `<user_prompt>`. Nothing in the packet is put on a command line; the caller sends it on
  stdin (A-2-0).

## Tests that must be able to fail

- A three-turn thread across three handles: the third packet contains both earlier answers.
- Blind packet: contains no text of the sibling answer (assert on a unique marker string in the sibling).
- `--with-prev` packet: contains the marker.
- Negative control: a copy of the function with the sibling filter removed makes the blind test fail.
