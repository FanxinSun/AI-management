# A-4-0 — SQLite store and append-only transcript

Step 0 of A-4 ([`../A-4.md`](../A-4.md)). Status: **pending**. File: `omni/store.py`.

## Database

`${OMNI_HOME}/omni.db`, opened with `PRAGMA journal_mode=WAL` and `PRAGMA foreign_keys=ON`. Tables:

- `threads(id TEXT PRIMARY KEY, title TEXT, created_at TEXT, active_handle TEXT, mode TEXT)`
- `turns(id TEXT PRIMARY KEY, thread_id TEXT REFERENCES threads(id), seq INTEGER, parent_turn_id TEXT REFERENCES turns(id), quoted_turn_id TEXT REFERENCES turns(id), kind TEXT CHECK(kind IN ('turn','compare','synthesis')), role TEXT CHECK(role IN ('user','assistant')), handle TEXT, model TEXT, effort TEXT, text TEXT, thinking TEXT, tools_json TEXT, created_at TEXT, duration_ms INTEGER, tokens_json TEXT)`
- `agent_sessions(thread_id TEXT, handle TEXT, native_session_id TEXT, last_synced_turn_id TEXT, PRIMARY KEY(thread_id, handle))`

`seq` counts turns in a thread from 1. A user turn has `parent_turn_id` set to the turn it follows; every assistant
turn answering it has that user turn as its parent, so answers to one prompt are siblings.

## Transcript

Every inserted turn is also appended as one JSON line (the row as an object) to `${OMNI_HOME}/transcripts/<thread_id>.jsonl`,
opened in append mode with `0600`, flushed and `os.fsync`ed. Nothing is ever deleted or pruned: the retention is
10 years by design. `export(thread_id, fmt, out)` writes `md` or `json` to `<out>.partial` and `os.replace`s it.

## Interface

`Store(home)`, `new_thread(title) -> id`, `add_turn(...) -> id`, `get_turn(id)`, `children(turn_id)`,
`chain_to_root(turn_id) -> list` (root first), `thread_turns(thread_id)`, `set_session(...)`, `get_session(...)`,
`list_threads()`, `export(...)`. Row counts of `turns` and lines of the transcript file agree after every `add_turn`;
a test checks that.
